---

## 🌟 Key Features

### 1. 🚪 Cinematic Halloween Gate Opening & VFX
- **Interactive 3D Gothic Iron Gates**: Heavy iron bar doors swing open in 3D perspective.
- **Lightning Flash & Screen Shake VFX**: Full-screen lightning flash and rumble upon unsealing.
- **Audio Synthesizer Engine**: Authentic 8-bit Lavender Town melody `[B4, C5, B4, F#4]`, thunderclaps, and Pokémon battle cries synthesized via the native Web Audio API (zero external broken links!).

### 2. 🧙‍♀️ Witch Vinita & ⚡ Wizard Amit Dual Leaders
- **Witch Vinita**: High Sorceress of Salem & Lavender Town (Ghost & Fairy type magic).
- **Wizard Amit**: Archmage of the Burned Tower & Void (Dark & Psychic type sorcery).
- **Interactive Dual Spells**:
  - `VINITA31`: 31% OFF Ghost-Type Couture.
  - `AMIT31`: 31% OFF Shadow Thunder Apparel.

### 3. 🌌 The 4-Region Dimensional Warp Gates
Warp seamlessly between regional atmospheres, music, and catalogs:
- 🟣 **Kanto (Lavender Crypt)**: Gastly, Haunter, Gengar, and Cubone skull relics.
- 🌙 **Johto (Burned Tower)**: Houndoom horn corsets, Umbreon shadow hoodies, and Sprout Tower chimes.
- 🎃 **Kalos (Laverre Haunted Manor)**: Super-Size Pumpkaboo onesies, Gourgeist fairy-witch gowns, and Aegislash coats.
- ☕ **Galar (Glimwood Tangle)**: Polteageist antique teapots, Morpeko hangry hoodies, and Grimmsnarl punk jackets.

### 4. 🧪 Interactive Minigames
- **Vinita & Amit's Cauldron Potion Brewery**: Drop regional ingredients (*Lavender Ectoplasm, Burned Tower Ash, Gourgeist Pulp, Polteageist Tea*) into the boiling cauldron to stir and brew secret discount potions!
- **Catch the Flying Ghost Pokémon**: Click wild ghost Pokémon as they fly across your screen for instant **25% OFF (`TRICKORTREAT`)** rewards!

### 5. 🍲 Full E-Commerce Store Engine
- **Cauldron Shopping Cart**: Real-time quantity adjustments, free shipping progress meter ($75 Haunter Express Delivery), and promo code verification.
- **Soul-Bound Wishlist**: Heart any relic to bind it to your crypt vault with persistent `localStorage`.
- **PokéWeen Wheel of Doom**: Physics-based fortune wheel giving out vouchers, Gengar pranks, and Rare Candies.
- **Crystal Ball Quick View Modal**: High-resolution custom SVG artwork, size/dimension selectors, customer ratings, and Vinita & Amit's lore.
- **Ritual Checkout**: Multi-step checkout simulation with custom `#POKE-XXXX` order confirmations.
- **Blood Moon Eclipse Mode**: Flips the entire emporium into a deep crimson lunar eclipse.

## 🚀 Quick Start

Run the static web server locally:

```bash
# Clone the repository
git clone https://github.com/parth-9292/vinita-the-witch-.git
cd vinita-the-witch-

# Run static server (Python)
python3 -m http.server 8080
```

Open `http://localhost:8080` in any web browser and click **"UNSEAL THE GATES"**!
